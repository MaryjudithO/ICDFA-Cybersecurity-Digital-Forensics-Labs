# Week 9: Cybersecurity Threats and Attack Techniques

**Cisco Networking Academy: Introduction to Cybersecurity** | Cybersecurity Threats and Attack Techniques

## Overview

This week focused on Cybersecurity Threats and Attack Techniques. Key concepts were reviewed and documented for portfolio development.

## Report Summary

- Explored malware types including viruses, worms, ransomware and trojans.
- Studied phishing, social engineering and identity theft techniques.
- Reviewed real-world cyberattack scenarios and common attacker objectives.
- Practiced identifying indicators of compromise and suspicious online behaviour.

## Lab Activities

1. Detect the EICAR test file
2. Analyse phishing email headers
3. Inspect links in the phishing email
4. Compare password strength
5. Observe reconnaissance on your own host

## Key Results

- AV detection can be verified safely using the EICAR test string.
- Email header and link analysis can reveal spoofing quickly.
- Password length contributes more to strength than simple substitutions.
- Reconnaissance shows what an attacker sees; scan only authorised targets.
