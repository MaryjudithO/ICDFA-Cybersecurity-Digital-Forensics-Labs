## Project Overview

This project explores how data travels across a network using the TCP/IP model through the scenario of opening a secure website (HTTPS).

The communication process is traced from the client device to the destination web server and back, demonstrating the interaction between the four TCP/IP layers, network devices, communication protocols, addressing methods, and data transmission processes.

---

## Project Objectives

This project aims to:

- Explain the functions of the four layers of the TCP/IP model.
- Demonstrate the communication process involved in accessing a secure website.
- Trace data movement from source to destination and back.
- Explain encapsulation and decapsulation.
- Identify the roles of IP addresses, MAC addresses, and port numbers.
- Compare TCP and UDP communication protocols.
- Apply a structured approach to troubleshooting network communication failures.
- Map the TCP/IP model to the OSI model.

---

## Selected Communication Scenario

**Opening a Secure Website (HTTPS)**

Example:

`https://www.amazon.com`

This scenario was selected because it demonstrates the complete operation of the TCP/IP model, including DNS resolution, TCP connection establishment, secure communication, routing, and data delivery.
